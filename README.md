# ローン・住宅ローン複数シナリオ比較ツール

金利・返済期間・借入金額の異なる最大3シナリオを横並び比較するツール。

## 機能

- 3列のシナリオ入力フォーム（借入金額・年利・返済年数）
- 元利均等返済で月返済額・総支払額・総利息を計算
- 総支払利息の棒グラフ比較（SVG/CSSバー）
- 繰上返済シミュレーション（追加月返済額入力→短縮月数・短縮年数を表示）
- localStorage で最後の入力値を保存

## 技術仕様

- バニラJS / Tailwind CDN
- XSSガード: escHtml() による innerHTML 無害化
- レスポンシブ対応（md:grid-cols-3）
- 全入力要素に aria-label 付与
